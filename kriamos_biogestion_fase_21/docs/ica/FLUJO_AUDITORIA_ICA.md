# Flujo operativo de auditoría ICA

## 1. Crear expediente

Se crea por granja y periodo. El sistema genera una matriz documental inicial.

## 2. Revisar matriz documental

Cada requisito se marca como:
- Pendiente
- Pendiente revisión
- Cumple
- No cumple
- No aplica

## 3. Registrar hallazgos

Los hallazgos se clasifican por criticidad:
- Baja
- Media
- Alta
- Crítica

## 4. Crear planes de acción

Cada plan debe tener:
- Acción correctiva
- Responsable
- Fecha compromiso
- Estado
- Avance

## 5. Generar paquete

El paquete organiza CSV y manifiesto de revisión interna.

## 6. Revisión técnica

La entrega oficial debe ser aprobada por responsables autorizados.
