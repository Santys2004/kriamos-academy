# Fase 08 - Reportes, impresión y exportación

## Reportes incluidos
1. Reporte de formatos diligenciados.
2. Reporte de alertas y vencimientos.
3. Reporte de certificaciones.
4. Reporte de incidencias de calidad.
5. Paquete documental ICA.

## Exportaciones
- CSV compatible con Excel.
- ZIP para paquete documental ICA.
- Vista imprimible HTML.

## Trazabilidad
Cada exportación relevante registra usuario, tipo de reporte, filtros aplicados, formato de salida, fecha y hora.

## Pendiente avanzado
Integración futura de PDF formal con Dompdf, mPDF o wkhtmltopdf.
